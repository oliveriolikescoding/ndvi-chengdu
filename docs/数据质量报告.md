| 项 | T1 | T2 |
|---|---|---|
| 成像时间 | 2025-01-03 03:59 UTC | 2026-01-12 03:50 UTC |
| 产品级别 | L2A（地表反射率） | L2A |

**为什么两期都是 1 月**：控制物候，避免"夏绿冬枯"被误读成"绿化变化"。代价是只能比较同期格局，不能代表全年水平。

**为什么用 2 个 tile 而不是 4 个**：研究区跨 48RUU(31.3%) / 48RVU(85.6%) / 48RUV(20.6%) / 48RVV(55.9%)，RVU+RVV 组合即可覆盖 >99.5%，其余 tile 只贡献边角。已验证。

## 3. 掩膜与填补的处理逻辑

1. **物理掩膜**：`DN > 0`，且 SCL ∉ {0,1,3,8,9,10,11}（无数据、饱和、云影、云（中/高概率）、薄云、雪）。
2. **反射率正性掩膜**：`red_r > 0.002 & nir_r > 0.002 & (red_r + nir_r) > 0.002`。这是本轮最关键的一条：BOA 偏移 −0.1 会把深色像元（水体边缘、阴影、新浇混凝土）压到 0 附近，分母趋零 → |NDVI| 爆表。不加这条，T1 有 4% 像元 |NDVI| > 0.95。
3. **小孔填补**：`scipy.ndimage.distance_transform_edt`，只在距有效像元 ≤2.5 px 的孤立孔洞里取最近邻值，其余保留 NaN。**不是**平滑、不是插值建模，只为消除掩膜留下的"麻点"，不改变空间格局。
4. **水体不掩**：保留负值，图上落在"非植被"档是正确的语义（水面 NDVI 本来就接近 0 或负）。

## 4. 两期可比性诊断（ΔNDVI 为什么做偏移校正）

| 检查 | 结果 | 判断 |
|---|---|---|
| 红光波段全区均值 | 0.032（T1）vs 0.023（T2） | 反射率整体水平不同 ≠ 地表变了 |
| 原始 Δ 中位 / 均值 | +0.125 / +0.135 | 72% 像元"改善"，不合常识 |
| 200×200 分块 Δ 标准差 | 0.043 | 分块间差异小 → 变化是全域性的 |
| 200×200 分块 Δ 最小值 | +0.045 | 连最"退化"的块也是正的 |
| 结论 | 大气/观测条件造成的整体偏移 | 扣全区中位 −0.125 后再分档 |

校正后：**改善 37.0% / 退化 36.0% / 稳定 27.0%**，5–95 分位 [−0.276, 0.319]，均值 +0.010（≈0）。原始数字一并保留在 `change_summary.json` 的 `raw` 节点，不做隐藏。
