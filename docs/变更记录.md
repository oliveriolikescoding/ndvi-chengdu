# 变更记录

## v1.0 · 2026-11-26

首版。W7 第 5 个 GIS 作品，主线是"用 Sentinel-2 算 NDVI 并出可交付专题图"。

**做了什么**

- 选景：`search_stac.py` 从 Earth Search STAC 取 2025-01 / 2026-01 两个冬季时相，云量 0.1% / 0.3%。
- 取数：`fetch_ndvi.py` 用 `gdalwarp /vsicurl` 按 bbox 取窗，2 tile 拼幅，反射率 BOA 校正，SCL 掩膜，NDVI，小孔填补 → `data/ndvi_T1.tif`、`data/ndvi_T2.tif`。
- 变化：`ndvi_change.py` 两期差值 + 全区中位偏移校正 → `data/ndvi_delta_norm.tif`、`data/change_summary.json`。
- 统计：`ndvi_stats.py` 9 个区县面积加权均值 → `data/ndvi_by_district.csv`（带 `clip_frac`）。
- 出图：matplotlib 版 A4 横版三合一（`ndvi_map.png/.svg/_gray.png`）+ QGIS 版单幅专题图（`ndvi_layout.pdf/.png/.svg`）。

**关键决策（后续改动前请先读这几条）**

| 决策 | 理由 | 反悔代价 |
|---|---|---|
| `CPL_VSIL_CURL_CHUNK_SIZE=1048576`（不是默认 10 MB） | 窗口只覆盖 1024×1024 的 COG 块，块太大会把"读一块"变成"拉 10 MB"。改小后单 tile 单波段从 ~450 s 降到 91 s | 改大 → 每次取数多 4–5 倍流量，本机网络下直接卡死 |
| 只按 bbox 取窗，不下载整景 | 整景 169–209 MB，本机用 requests/curl 实测 0 字节卡死 | 回退整景下载 = 回退到不可用 |
| 有效像元加"反射率正性掩膜" `red_r>0.002 & nir_r>0.002 & denom>0.002` | BOA 偏移 −0.1 使深色像元分母趋零。只判 `DN>0` 时 4% 像元 \|NDVI\|>0.95 | 去掉 → 极值像元翻倍，图上出现黑/白噪点 |
| 变化量扣全区中位偏移（−0.1246）后再分档 | 两期红光均值 0.032 vs 0.023，原始 Δ 中位 +0.125、72% 像元"改善"，分块标准差仅 0.043，判为大气偏移 | 不扣 → 结论变成"全城复绿"，是错的 |
| 图幅固定 A4 横版 297×210 mm、比例尺按纸面反算 | 交付规格统一，客户可直接打印 | 改尺寸 → 比例尺、注记位置全要重算 |
| 中文字体 SimSun + 西文 Times New Roman | 用户口径（图件不随风格项目变更） | — |
| QGIS 版图例自绘（不用 `QgsLayoutItemLegend`） | 内置图例会带出 `Band 1 (Gray)` 噪声行，且 3.44 的 `setStyleFont` 已废弃 | 换回内置图例 → 图例多两行无用条目 |

**环境侧改动（会在交付说明里登记）**

- Anaconda base 环境升级/降级 `affine` 到 `2.3.0`：rasterio 1.3.11 与 affine 3.x 不兼容，会报 `No '__dict__' attribute on 'Affine' instance`。
- 新增 `geoenv.py`：本机 `PROJ_LIB` 被 PostgreSQL/PostGIS 的 proj 目录占用（无 `proj.db`），所有 EPSG 查询失败。脚本内置把 `PROJ_LIB/PROJ_DATA` 指向 rasterio 自带的 `proj_data`，**必须在 rasterio 导入之前 import**。
- QGIS 侧运行需 `QT_QPA_PLATFORM=offscreen`、`QT_QPA_FONTDIR=C:\Windows\Fonts`，否则无头环境取不到字体。

**已知未做**

- 未做几何精校正；两期同名点可能有 1–2 px 偏移，变化图的高频噪点部分来源于此（已在图注与质量报告 Q-06 声明）。
- 未做真彩色底图叠加；只用区县界线做定位。
- 未接 Sentinel-1（云雨天气下的替代源），留作后续。
