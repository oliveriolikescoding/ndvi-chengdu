# 数据来源与许可

> 交付或对外展示时，这一份要能直接贴给客户看。每个源单列，许可写全，抓取方式写清。

## 1. 卫星影像

| 项 | 内容 |
|---|---|
| 产品 | Sentinel-2 **L2A**（Level-2A 地表反射率，含 SCL 场景分类层） |
| 提供方 | ESA / Copernicus（欧盟哥白尼计划） |
| 许可 | **Public Domain**（Copernicus 数据政策，允许商用、再分发，需注明来源） |
| 检索接口 | Element 84 **Earth Search** STAC：`https://earth-search.aws.element84.com/v1/search`，collection `sentinel-2-l2a` |
| 数据托管 | AWS Open Data，COG（Cloud-Optimized GeoTIFF）直读，无需账号 |
| 下载方式 | GDAL `/vsicurl/` 按研究区窗口读取（只取 1552×2315 像元，不下载整景） |
| 访问时间 | 2026-11-26 |
| 使用场景 | T1 `S2B_48RVU_20250103_0_L2A`、`S2B_48RVV_20250103_0_L2A`（2025-01-03）<br>T2 `S2A_48RVU_20260112_0_L2A`、`S2A_48RVV_20260112_0_L2A`（2026-01-12） |

**注意**：2026 年起 Sentinel-2 的获取入口有调整（原"自由开放"政策下的旧入口逐步迁移），本项目使用的是仍开放的 AWS Open Data 镜像，与 ESA 官方产品同源同版本（processing baseline 05.11）。

## 2. 行政界线（底图）

| 项 | 内容 |
|---|---|
| 内容 | 成都市 20 个区（市）县边界（`data/basemap/chengdu_districts.json`，GeoJSON，WGS 84） |
| 来源 | **DataV.GeoAtlas**（阿里云可视化平台行政区划数据） |
| 许可 | 平台公开下载，**无明确商用授权条款**；按"仅作空间参照"使用 |
| 精度 | 概化边界，节点精度约 0.01°，**非法定界线** |
| 用途 | 图上定位与区县统计的空间单元 |

**红线**：不得用于权属认定、行政边界测绘成果、任何需要法定效力的场景。图面已逐张标注"非法定界线"。
