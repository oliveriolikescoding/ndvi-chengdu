# 遥感踩坑速查（本机实测，2026-11-26）

五条都是这周真的卡住过、又真的被解掉的坑。按「现象 → 原因 → 做法」写，下次换个区域换个卫星直接照抄。

## 1. Sentinel-2 L2A 的 DN 不是反射率，必须做 BOA 偏移

**现象**：直接拿 DN 算 NDVI，水体算出 +0.3、城区算出 −0.5，值域跟常识对不上。

**原因**：L2A 产品为兼容旧格式，DN 存的是 `(ρ + 0.1) / 0.0001`，即带 BOA_ADD_OFFSET。红光在裸地可能为 0 或接近 0，直接除会炸。

**做法**：`ρ = DN * 0.0001 - 0.1`，再算 `NDVI = (ρNIR - ρRED) / (ρNIR + ρRED)`。scale/offset 别写死，从 STAC 的 `assets.<band>["raster:bands"][0]` 里读，不同产品版本会变。

## 2. SCL 掩膜要按集合删，不是只删云

**现象**：图上出现成片 NDVI ≈ 0 的畸形条带，看着像数据坏了。

**原因**：只掩膜了云（class 9），云影（8）、积雪（11）、饱和（1）、黑影（3）都还在。冬季影像尤其容易被积雪和云影污染。

**做法**：把 `(0,1,3,8,9,10,11)` 一起设成无效（0=无数据、1=饱和、3=云影、8=云中影、9=云高置信、10=卷云、11=雪）。水体（6）保留但要单独统计，别混进植被统计。

## 3. 大范围别下整景，让 GDAL 自己按块取窗

**现象**：169 MB 的整景，`requests` / `curl` 下载直接 0 字节卡死；`PowerShell` 能跑起来但持续吞吐掉到 70 KB/s。

**原因**：到 `sentinel-cogs.s3.us-west-2.amazonaws.com` 的短区间请求很快（8 MB / 2.3 s），但长连接会被限速。整景下载不可行。

**做法**：不下载，直接 `gdalwarp /vsicurl/https://...` 按 `-te` 窗口读。只要窗口占整景的几十分之一，读的就是几十 MB 而不是 169 MB。

## 4. `CPL_VSIL_CURL_CHUNK_SIZE` 有硬上限，超了会静默变慢

**现象**：把 chunk 设成 64 MB，日志里一句警告，然后单景取窗从 100 s 变成 400 s+。

**原因**：GDAL 允许的分块是 1024–10485760 字节，超限静默回退到 16384。**16 KB 的块 = 每个块一次 HTTP 请求**，等于自杀。

**做法**：设成上限 `10485760`，配 `CPL_VSIL_CURL_CACHE_SIZE=268435456`、`VSI_CACHE=TRUE`、`GDAL_DISABLE_READDIR_ON_OPEN=EMPTY_DIR`、`CPL_VSIL_CURL_ALLOWED_EXTENSIONS=.tif`（省掉对 `.tif.msk` 之类附属文件的探测请求）。

## 5. 窗口范围必须用 pyproj 真算，不能估

**现象**：`gdalwarp -te` 用了手估的 UTM 范围，输出全 0 像素，`STATISTICS_VALID_PERCENT=0`，但进程返回码是 0（不报错）。

**原因**：经纬度→UTM 的换算不是线性缩放，估出来的框能偏出半个图幅；gdalwarp 对「源窗口部分超出景范围」只在 stderr 里打一行提示，不报错。

**做法**：用 `pyproj.Transformer` 把 bbox 四角转到目标 CRS，取外包框，再按目标分辨率对齐取整；跑完立刻查有效像元比例，低于 90% 就回头查范围。

## 附：环境相关的三条

- **PROJ 被污染**：系统 `PROJ_LIB` 可能指向 PostgreSQL 的 postgis proj 目录（没有 `proj.db`），所有 EPSG 查询报 `Cannot find proj.db`。在任何 rasterio 导入**之前**把 `PROJ_LIB` / `PROJ_DATA` 指到 `rasterio/proj_data` 或 QGIS 的 `share\proj`。
- **affine 版本**：`affine 3.0.x` 与 `rasterio 1.3.x` 不兼容（`No '__dict__' attribute on 'Affine' instance`），降到 `affine==2.3.0`。
- **同一个影像跨两个 tile**：成都这个框跨 48RVU + 48RVV 两个瓦片，单个 tile 只能覆盖 85%，必须两幅拼。拼幅直接给 gdalwarp 两个 `/vsicurl` 输入即可，不用先各自裁再 merge。
